# Wedding Studio

Dự án đang phát triển nằm tại **wedding-studio/**, sử dụng Laravel 12 và PHP 8.2+.

- Hướng dẫn: [wedding-studio/README-VI.md](wedding-studio/README-VI.md)
- Trang xem thử: http://127.0.0.1:8000
- Trang quản trị: http://127.0.0.1:8000/admin
- Chạy: vào wedding-studio, dùng `php artisan serve --host=127.0.0.1 --port=8000`.

Database xem thử là SQLite. Khi đưa lên hosting, cấu hình MySQL trong .env theo hướng dẫn. Chưa triển khai lên server thật.

Repo chỉ chứa dự án Laravel hiện tại; các công cụ cài đặt và bản thử nghiệm cũ được giữ ngoài Git.
